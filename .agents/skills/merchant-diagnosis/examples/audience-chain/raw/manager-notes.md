# 11月8日老板与店长记录

合成经营访谈，非真实商家回执。

老板：这轮先看商家的经营贡献和完成单。不要只把亏的单停掉就说经营好了。暂定同口径单均经营贡献至少8元算达到我的要求；净收入比前周增长5%是本月筛选增长店的工作目标，两个阈值只是这次品牌目标，不是行业标准。每家店的原账已给，直接用；没有把房租和固定员工工资放进来，所以别叫净利润。

运营：六店权限不同。总部能改直营店菜单和会员活动；滨江、学府是加盟店，由加盟商老板拍板。投放权限由总部运营管理，不能假设服务人员能直接调预算。请把总部确认、店长操作、财务回传分清。

学府店：10/19供货改成每日60份鸡腿，之前是100份；午峰补货赶不上，19次午餐售罄记录。退款从前周55单到本周140单，退款理由中“主套餐无货换菜不接受”105单，前周同类20单。同期价格、配送半径和营业时间没变。先把供给及售罄记录核清，不想在套餐缺货时加推广。

城西店：午餐打包岗缺人，日常排班没补齐，午餐不能接更多单。晚餐还有8单/日余量。没有把这8单当作肯定新增的订单。

滨江店：最近多单来自满减，券由加盟商全部承担。本周商家券23,800元。价格和套餐调整要和加盟商确认；没有可用的平台共投政策，不要先算补贴收入。

社区店：广告费确实为0，不是缺数。维持现有家庭套餐和会员自提，新增客群触达要另做判断。

责任安排：总部运营确认试点范围和活动上限；国贸/科创店长确认商品、库存与午晚容量；加盟动作先找加盟商老板；财务按同样费用字段回传周账。准备、排班、上线截图与实际领券/核销要留回执，没人提交就记未核实执行。

会员运营：现在高频客每月发5元通用券，其他人群沿用原菜单的常规触达。希望知道哪些该换商品权益，哪些继续发券是在给自然订单折价。观察只是模拟，不是已经做过的营销。新一轮别把所有群都塞同一张券。

总部资源：国贸/科创允许在11/09–12/08做一轮定向权益。可触达上限、商品单均成本和临时执行费都已确认在本材料，不用再索整套财务表。对增长群只按观察增量的60%做预算；高频无券按420完成单/千人测算。品牌内跨店用户已去重，不追加触达次数。本月可用人群只用一轮，不把同一批人反复乘周数。

配品供应：双主菜券仅用于双主菜随心配，不能与通用券叠加。首购第二单权益为单人能量餐减2元。晚餐召回是晚餐热食组合减5元。日常自然菜单保持原价；未核销券成本为0，商家只承担完成订单已核销金额。

供给上限：国贸最多增加40单/日（午20、晚20），科创最多35单/日（午15、晚20）。未来人群按60%/40%分配；试行可将增量订单按午40%/晚60%排，实际回传必须按时段核，不以全日余量掩盖午餐超量。增量商品费用已按单列，额外执行费总额1,800元，不另加固定编制。

复盘要求：先跑7天看有效触达、核销、成熟完成单、退款和贡献，确认没有低价替代过多、午峰超量再继续。对取消高频券要同时看完成单变化；若实际单量低于预算用的420单/千人，先重算贡献再决定是否恢复权益。出现未执行、额外成本或容量不够时，记录原因为不会操作、资源不足或权限未确认，再改方案；没有执行回执不登记为增长成果。
