# 表头映射预览与确认设计

- 日期：2026-11-01
- 状态：用户已确认方向

## 流程

上传 CSV／XLSX → 只读取表头 → 展示原字段→标准字段、匹配方式、缺失项和模块开放状态 → 用户确认 → 按确认映射解析与计算。

## 规则

- 标准字段精确匹配优先；有限规则别名只作为待确认建议，不调用模型改口径。
- 多个原字段映射到同一标准字段时阻断，要求保留唯一权威来源。
- 必需字段缺失时禁用确认按钮；未识别的额外字段保留展示但不阻断。
- 流量模块需要曝光＋进店；用户模块需要复购率＋会员占比；缺一组只关闭对应模块。
- 映射通过不代表数据质量通过，重复工具、零消耗分母、归因不一致等仍按原规则处理。
- 预览与生成使用同一个文件和同一份映射，换文件必须重新预览。

## 输出

- 原字段、标准字段、精确匹配／规则别名／未映射。
- 缺失必需字段、重复映射、可生成状态。
- 经营与投放、流量转化、用户经营模块的开放或关闭原因。
- 明确提示“字段映射不等于指标口径已确认”。
