# 手动表头映射校正设计

- 日期：2026-11-01
- 状态：用户已确认方向

## 交互

表头预览每行提供标准字段下拉框，可选必需字段、可选字段或“不纳入诊断”。修改后立即重新计算缺失项、重复映射、模块开放状态和确认按钮。

## 规则

- 自动匹配保持不变；用户改动标记为“手动校正”。
- 手动映射可解决未知列或错误别名，但多个原字段指向同一标准字段仍阻断。
- 必需字段被手动排除时立即显示缺失并禁用确认。
- 最终解析使用当前手动校正后的映射，不使用初始自动映射。
- 换文件重新读取并生成初始映射，防止旧校正串用到新文件。

## 验收

- 未知列可手动映射为净 GMV 后生成诊断。
- 手动制造重复映射会禁用按钮，改回后可恢复。
- 手动排除必需字段会立即显示缺失。
- 桌面、移动和既有上传流程无回归。
