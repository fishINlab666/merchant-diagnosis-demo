# 四项 P1 验收修复设计

- 日期：2026-11-01
- 状态：用户已确认修复方向

## 1. 门店身份

- `StoreProfile` 增加门店 ID，`WeeklyReport` 保存文件原始门店 ID。
- 文件预览同时展示档案门店 ID 与文件门店 ID；档案未填时，确认生成即认可归属并在生成后绑定。
- 两者均填但不一致时禁止生成，并显示具体差异。
- 文件门店 ID 为空时拒绝解析。

## 2. 合成样本隔离

- 仅 `report.synthetic=true` 的演示案例使用合成竞店和城市分层。
- 真实上传不传入合成样本，竞店与城市模块不展示。

## 3. 公开检索

- 按 Bing → DuckDuckGo 顺序尝试公共读取；失败、验证码或无有效文本时继续下一家，全部失败后转人工。
- 每个结果保留真实搜索 URL、采集时间和摘要，不把验证码或拒绝页当证据。

## 4. 受约束 AI 与规则回退

- AI 仅接收公开搜索摘要，不接收 CSV／XLSX、用户级数据或精确地址。
- 任务限定为从 `rating_reviews/menu_structure/price_sensitivity/insufficient_data` 中选择一个待验证方向。
- 只接受白名单 ID；其他文本、未知 ID、调用失败均回退本地规则。
- 本地规则负责事实、数字、解释和后续诊断，AI 不新增指标、原因或收益承诺。

## 验收

- 错门店 ID 被阻断；未填 ID 的文件在确认归属后绑定。
- 真实上传不出现合成竞店或城市分层，合成案例保留。
- 实测公共搜索可返回内容；失败路径可人工继续。
- AI 使用、AI 失败回退和非法 ID 回退均有测试，真实周报不发起 AI 请求。
