# 导师参考 Case 融合与 Google 扁平视觉设计

日期：2026-11-03
状态：已确认落地开发

## 目标

把参考 case 中有助于面试演示和商家决策的能力融入现有 Merchant OS：店铺页文本初诊、评价主题与竞店对比、8 周趋势、工具效率、预算结构、收益拆解、老板追问、一键演示和复制话术。视觉改为 Google 四色的扁平化界面。

## 保留的产品边界

- 继续使用现有 React + TypeScript + Vite、周报映射、人工字段校正、六维诊断、预算计算和打印流程。
- 只服务商家单店诊断，不恢复三角色切换、186 店分层或 SaaS 续费健康度。
- 公开信息只产生待验证候选问题；周报才支撑经营结论和预算动作。
- 真实上传不生成合成历史、竞店或城市数据。所有演示序列均由 `report.synthetic` 门控。
- 测算展示假设，不使用收益保证口吻。

## 模块设计

### 1. 店铺页文本初诊

`src/domain/intake.ts` 增加纯函数 `parsePublicIntake(text)`。提取店名、评分、月售、人均、起送、配送费、配送时长、菜单、评价和可选竞店行；按配送慢、送到变凉、分量、口味四类主题聚类并保留原文。

`PublicIntakeView` 提供文本输入、合成示例填充、事实摘要、评价主题、竞店对比和最多三个“事实 → 候选原因 → 建议 → 周报 CTA”。无文本或证据不足时显示缺失项，不推测 ROI、转化或利润。

### 2. 趋势和方案图

`demoSeries.ts` 以固定系数生成确定性的 8 周合成序列，最后一周严格等于当前周报；真实周报返回空数组。

`Charts.tsx` 提供无新增依赖的 SVG/HTML 图：

- `WeeklyTrend`：净 GMV、推广费、整体 ROI。
- `ToolEfficiencyBars`：消耗占比、ROI 和最低效率工具。
- `BudgetMix`：现在和建议预算结构。
- `ProfitWaterfall`：预算、补贴、订单流失及新增消耗对毛利的贡献。

### 3. 测算扩展

`Assumptions` 增加可选 `period: 'week' | 'month'` 和 `subsidyOrderLossRate`。默认周周期、40% GMV 流失折算，保持既有默认结果逐分不变。月周期使用 4.3 周；只有降低商家补贴时扣除对应 GMV 流失。

假设面板使用数字输入和滑块，保留原有无障碍标签和输入约束。`Calculation` 增加贡献拆解字段，图表直接消费计算结果，不另写一套公式。

### 4. 老板追问和演示

`bossQuestions.ts` 为四个固定问题生成绑定当前证据的离线答案。合成案例可尝试受限 AI 文本回答；超时、失败、新增数字或保证性措辞均回退离线答案。真实周报只使用本机离线答案。

`DemoWalkthrough` 增加“一键完整演示”和逐步讲解，仍调用真实的六阶段计算，支持 reduced-motion。`ReportView` 增加复制三句话，Clipboard 不可用时展示可手动选择文本。

### 5. Google 扁平视觉

- 品牌蓝 `#4285F4`，错误红 `#EA4335`，提醒黄 `#FBBC04`，成功绿 `#34A853`。
- 正文 `#202124`，次级文字 `#5F6368`，背景 `#F8FAFC`，边线 `#E0E3E8`。
- 品牌按钮、选中态和决策头部使用蓝；错误保持红，成功保持绿。
- 使用 6—12px 圆角、清晰边线和留白；禁止渐变、玻璃拟态、装饰性阴影。
- 桌面保持决策层级，移动单列，打印保留一页行动方案。
