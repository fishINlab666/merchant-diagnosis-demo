# 展示报告的运行证据

这些文件来自合成案例的实际运行，原始报告 JSON、执行状态与计算记录按原文件保留。输入材料见仓库 Skill 的 examples；不包含本机配置、密钥、个人材料或私有路径。

`single/` 对应 Codex CLI 的单店运行。宿主模式 `model_calls=0` / `inference_executed=false` 只表示 Python 脚本没有另外调用 API，宿主模型的分析实际在 Codex 会话中进行。其首次使用记录含一次输出路径修正，报告首稿通过。

网页是对上述 JSON 的展示，不能把条件测算解释为真实经营改善。详细门禁与其他场景见仓库 ACCEPTANCE.md。

`public-initial/` 为宿主重新核对原材料后完成的公开初诊修订。先前 API 技术链路完成但独立 Codex 审阅未过，后续 API 修订失败；二者未作为本页初诊成稿。完整历史状态见验收记录。

`chain/` 对应 Codex 宿主从三份原件重新分析、计算和导出的正式连锁看板。12项计算与来源经过独立复核。该代理此前看过另一轮失败API的候选稿，因此不是未见旧稿的盲跑；该旧稿未作为本轮输入。它也不充当独立API成功证据。

`recorded-chain/` 对应本次操作录屏里的全新 Codex CLI 会话。最终 12 项计算、56 个变量逐源重算通过，主金额 18,000 元；实际 12 个命令工具步骤，含来源引用、计算编号冲突和导出单位的自行修复。录屏与对应报告都保留该次真实结果，不使用正式固定案例替换。
